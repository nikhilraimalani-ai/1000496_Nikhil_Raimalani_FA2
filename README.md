# SustainStyle

Scan a clothing tag, see its real environmental impact, swap to something better and earn GreenPoints.
A mobile-first Streamlit app built for CRS Critical and Creative Thinking, FA 2.

## Features
- **Scan:** barcode simulation, manual barcode entry and camera or photo input
- **Eco-Score engine:** weighted score from Materials 35%, Carbon 25%, Water 25%, Labour 15%, with grades A to E and a traffic-light verdict
- **Everyday units:** carbon as km of driving, water as years of drinking water
- **Greener swaps:** 22-item catalogue, ranked alternatives, filters (Cheaper, Pre-loved, Repair, New), savings in rupees, water and CO₂
- **GreenPoints:** levels, streak tracker, weekly chart, badges, rewards store, community leaderboard
- **Profile:** Eco Impact Score share card, outfit ideas, closet, settings (larger text)

Product names and numbers are made up. Scanning is simulated.

## Run locally
```
pip install -r requirements.txt
streamlit run app.py
```
