# SustainStyle

Eco-App in Action (CRS Critical and Creative Thinking, FA 2). A Streamlit prototype of the SustainStyle mobile app.
Scan a clothing tag, see an item-level Eco-Score (0 to 100, grade A to E), get cheaper and greener alternatives, and earn GreenPoints.

## Screens (from the FA-1 storyboard)
1. Home: Scan-ready (scan, paste link, guest mode)
2. Scan the item (Barcode, Photo, Type it)
3. Eco-Score result (four-factor breakdown, data confidence, how it is calculated)
4. Greener and cheaper swaps (budget, size and style filters, Pause & Skip)
5. Decision and reward (+GreenPoints, water and money saved, streak)
6. My Impact and Customize (vouchers, challenge, settings) plus a Closet tab

Product names and numbers are made up. Scanning is simulated.

## Run locally
```
pip install -r requirements.txt
streamlit run app.py
```
